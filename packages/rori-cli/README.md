# rori-cli

Global **`rori`** command — same runtime as [Command Code](https://commandcode.ai/) (`command-code`), branded for the Rori AI + llm-adaptor Gemini Web workflow.

```powershell
npm i -g command-code@latest
npm i -g D:\source\llm-adaptor\packages\rori-cli
rori --local-only --list-models
```

Configure BYOK: `scripts/setup-rori-bridge.ps1` in the llm-adaptor repo.
